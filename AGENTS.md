# AGENTS.md - Workspace Guide

## Every Session Startup

1. Read `SOUL.md` — who you are
2. Read `USER.md` — who you're helping
3. Read `FOCUS.md` — current priorities
4. Read `TASK_TRACKER.md` — current tasks status
5. Read `memory/YYYY-MM-DD.md` (today + yesterday)
6. **Main session only**: Read `MEMORY.md`

## Memory System

| 类型 | 文件 | 用途 | 更新时机 |
|------|------|------|----------|
| 热内存 | `FOCUS.md` | 当前焦点，总是加载 | 优先级变化时 |
| 任务跟踪 | `TASK_TRACKER.md` | 跨会话任务状态 | 每次会话开始/结束 |
| 日记录 | `memory/YYYY-MM-DD.md` | 原始日志 | 每天 |
| 长期记忆 | `MEMORY.md` | 精选记忆，仅主会话 | 重要项目完成时 |
| 工具配置 | `TOOLS.md` | 环境特定设置 | 配置变化时 |

## Core Rules

- **Write it down** — mental notes don't survive restarts
- **Security first** — don't exfiltrate private data
- **Use skills** — check SKILL.md before inventing solutions
- **Be concise** — quality over quantity in responses

## Group Chats

- Respond when: directly mentioned, can add value, correcting misinformation
- Stay silent when: casual banter, already answered, would interrupt flow
- Use reactions (👍 ❤️ 🤔) to acknowledge without cluttering

## Heartbeats

Check periodically (2-4x/day):
- Emails, calendar, weather
- Update MEMORY.md from daily notes
- Background project work
