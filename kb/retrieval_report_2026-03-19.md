## 三、按疾病分类的知识库构建

### 3.1 青光眼 (Glaucoma)

#### 核心指南
- **AAO POAG首选实践模式 (2020)** - DOI: 10.1016/j.ophtha.2020.10.022
- **欧洲青光眼学会指南第5版 (2021)** - DOI: 10.1136/bjophthalmol-2021-egsguidelines

#### 关键临床试验
- **LiGHT研究**: SLT vs 眼药水一线治疗 - Lancet 2019
- **UKGTS研究**: 拉坦前列素治疗POAG - Lancet 2014
- **MIGS系统综述**: 微创青光眼手术 - PLoS ONE 2017

#### 知识库要点
```
✓ 前列腺素类似物为一线药物治疗
✓ SLT可作为一线治疗替代眼药水
✓ MIGS适用于轻中度POAG
✓ 小梁切除术用于进展期/难治性病例
```

### 3.2 白内障 (Cataract)

#### 核心指南
- **超声乳化技术改进指南 (2021)** - DOI: 10.3390/healthcare9111603
- **白内障手术知情同意指南 (2007)** - DOI: 10.1177/014107680710000226

#### 关键临床研究
- **白内障手术并发症率研究** - Ophthalmology 2007
- **白内障-青光眼联合手术** - Curr Opin Ophthalmol 1998
- **白内障手术可持续性** - Ophthalmology 2020

#### 知识库要点
```
✓ 超声乳化是目前主流手术方式
✓ 术前评估包括角膜内皮计数、眼轴测量
✓ 表面麻醉、球周麻醉、Tenon囊下麻醉可选
✓ 术后抗生素+激素眼药水管理
```

### 3.3 视网膜脱离 (Retinal Detachment)

#### 核心指南
- **SPR研究**: 巩膜扣带术 vs 玻璃体切除术 - Ophthalmology 2007
- **Cochrane系统综述 (2019)** - DOI: 10.1002/14651858.cd009562.pub2

#### 关键临床研究
- **PPV vs 巩膜扣带术治疗人工晶体眼RD** - Retina 2005
- **下方裂孔RD的PPV+气体治疗** - Br J Ophthalmol 2004

#### 知识库要点
```
✓ 年轻患者、晶状体透明 → 巩膜扣带术
✓ 人工晶体眼 → PPV
✓ 下方裂孔 → PPV+巩膜扣带术或气体填充
✓ 复杂RRD → PPV
```

### 3.4 葡萄膜炎 (Uveitis)

#### 核心指南
- **ASAS/EULAR强直性脊柱炎管理推荐 (2011)** - DOI: 10.1136/ard.2011.151027
- **脊柱关节病关节外表现管理 (2023)** - DOI: 10.1111/1756-185x.14485

#### 关键临床研究
- **JIA-U筛查指南** - Rheumatology 2007
- **激光闪辉值监测JIA-U** - Acta Ophthalmol 2011

#### 知识库要点
```
✓ HLA-B27相关葡萄膜炎：局部激素+睫状肌麻痹剂
✓ 复发预防：抗TNF-α药物（阿达木单抗）
✓ JIA-U：LF >20 photon units/ms 预示并发症风险
✓ 难治性病例：甲氨蝶呤、硫唑嘌呤
```

### 3.5 年龄相关性黄斑变性 (AMD)

#### 核心指南
- **AAO AMD首选实践模式 (2019)** - DOI: 10.1016/j.ophtha.2019.09.024

#### 关键临床研究
- **RESTORE研究**: 雷珠单抗治疗DME - Ophthalmology 2011
- **抗VEGF耐药综述** - Drug Des Devel Ther 2016
- **延长给药策略** - Graefes Arch Clin Exp Ophthalmol 2021

#### 知识库要点
```
✓ 抗VEGF为nAMD一线治疗
✓ 可选药物：雷珠单抗、阿柏西普、法瑞西单抗
✓ 存在抗VEGF耐药现象
✓ 可尝试延长给药间隔（Treat-and-extend）
```

### 3.6 糖尿病视网膜病变 (DR)

#### 核心指南
- **国际糖尿病眼病指南 (2018)** - DOI: 10.1016/j.ophtha.2018.04.007
- **AAO DR首选实践模式 (2019)** - DOI: 10.1016/j.ophtha.2019.09.025

#### 关键临床研究
- **DR流行病学** - Eye and Vision 2015
- **深度学习筛查DR** - JAMA 2017

#### 知识库要点
```
✓ 1型糖尿病：5年后或12岁开始筛查
✓ 2型糖尿病：确诊时开始筛查
✓ 筛查频率：每年1次（无DR者）
✓ 治疗：激光光凝、抗VEGF、玻璃体切除
```
