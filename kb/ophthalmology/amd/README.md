### Faricimab治疗新生血管性AMD
- **文献**: Efficacy, durability, and safety of intravitreal faricimab up to every 16 weeks for nAMD (TENAYA and LUCERNE)
- **来源**: The Lancet (2022)
- **DOI**: 10.1016/s0140-6736(22)00010-1
- **被引**: 628次
- **开放获取**: ✅ 是
- **URL**: http://www.thelancet.com/article/S0140673622000101/pdf
- **研究类型**: 两项随机、双盲、3期、非劣效性试验
- **关键发现**:
  - Faricimab每16周给药显示良好疗效
  - 非劣效于标准治疗
  - 延长给药间隔减少患者负担

## 临床要点速查

### AMD分型
| 类型 | 特征 |
|------|------|
| 早期AMD | 中等大小玻璃膜疣 (<63μm) |
| 中期AMD | 大玻璃膜疣 (≥125μm) 和/或 视网膜色素异常 |
| 晚期AMD | 新生血管性AMD 或 地图样萎缩 |

### nAMD治疗
- **一线**: 抗VEGF（阿柏西普、雷珠单抗、法瑞西单抗）
- **治疗-延长**: 根据疾病活动调整间隔
- **PCV**: 抗VEGF ± PDT

### GA治疗（新兴）
- Pegcetacoplan（补体C3抑制剂）
- Avacincaptad pegol（C5抑制剂）
