## 临床要点速查

### OCT检查适应证
| 疾病 | OCT应用 |
|------|---------|
| AMD | 黄斑厚度、CNV检测 |
| DME | 视网膜厚度量化 |
| 青光眼 | RNFL厚度、GCC分析 |
| 视网膜脱离 | 玻璃体视网膜界面 |
| 黄斑裂孔 | 分期、随访 |

### AI辅助诊断要点
1. **适用场景**: 大规模筛查、辅助诊断
2. **限制**: 不能替代医生判断
3. **质量控制**: 图像质量影响AI准确性
4. **法规**: 需符合医疗器械审批要求

### 影像数据标准
- **DICOM**: 医学影像标准格式
- **分辨率**: 至少512×512像素
- **质量控制**: 信噪比、运动伪影检查
