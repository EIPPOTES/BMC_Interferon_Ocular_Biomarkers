## 临床要点速查

### DR分级标准
| 分级 | 特征 |
|------|------|
| 无DR | 无视网膜病变 |
| 轻度NPDR | 微动脉瘤 |
| 中度NPDR | 微动脉瘤+硬性渗出/棉絮斑 |
| 重度NPDR | 任意象限静脉串珠，或2+象限IRMA，或1+象限显著IRMA |
| PDR | 新生血管形成 |

### DME分型
| 类型 | 定义 |
|------|------|
| 中心性DME | 黄斑中心1mm范围内有增厚 |
| 非中心性DME | 黄斑增厚但不涉及中心 |

### 治疗指征
- **中心性DME**: 抗VEGF治疗（一线）
- **PDR**: PRP激光或抗VEGF
- **高危PDR**: 及时激光或玻璃体手术
