## 临床要点速查

### 葡萄膜炎分类
| 解剖位置 | 定义 |
|----------|------|
| 前葡萄膜炎 | 虹膜和睫状体炎症 |
| 中间葡萄膜炎 | 玻璃体炎症为主 |
| 后葡萄膜炎 | 视网膜/脉络膜炎症 |
| 全葡萄膜炎 | 累及所有部位 |

### 治疗原则
1. 控制炎症
2. 预防并发症
3. 维持视力
4. 最小化药物副作用
