## 手术技术

### 飞秒激光辅助 vs 超声乳化白内障手术
- **文献**: Femtosecond laser-assisted versus phacoemulsification cataract surgery (FEMCAT)
- **来源**: The Lancet (2020)
- **DOI**: 10.1016/s0140-6736(19)32481-x
- **被引**: 119次
- **开放获取**: ✅ 是
- **URL**: http://www.thelancet.com/article/S014067361932481X/pdf
- **研究设计**: 多中心、患者盲法、随机优效性和成本效益试验
- **主要结论**:
  - 飞秒激光辅助白内障手术的优效性需进一步评估
  - 成本效益分析显示传统超声乳化更具优势

### 全球白内障手术实践模式
- **文献**: Cataract surgery practice patterns worldwide: a survey
- **来源**: BMJ Open Ophthalmology (2021)
- **DOI**: 10.1136/bmjophth-2020-000464
- **被引**: 147次
- **开放获取**: ✅ 是
- **URL**: https://bmjophth.bmj.com/content/bmjophth/6/1/e000464.full.pdf

### 即刻vs延迟序贯双侧白内障手术

- **来源**: PLoS ONE (2015)
- **DOI**: 10.1371/journal.pone.0131857
- **被引**: 61次

## 临床要点速查

### 手术时机
| 情况 | 建议 |
|------|------|
| 视力影响日常生活 | 手术指征明确 |
| 最佳矫正视力 <0.5 | 考虑手术 |
| 晶状体源性青光眼 | 急诊手术 |
| 高度近视白内障 | 个性化方案 |

### 人工晶状体选择
| 类型 | 适应证 |
|------|--------|
| 单焦点 | 常规病例 |
| 多焦点 | 希望减少眼镜依赖 |
| 散光矫正 | 角膜散光 >1.0D |
| 景深延长 | 兼顾远近视力 |

### 术后并发症
| 早期 | 晚期 |
|------|------|
| 角膜水肿 | 后囊膜混浊 |
| 高眼压 | IOL脱位 |
| 前房炎症 | 黄斑囊样水肿 |
| 感染 | 视网膜脱离 |
