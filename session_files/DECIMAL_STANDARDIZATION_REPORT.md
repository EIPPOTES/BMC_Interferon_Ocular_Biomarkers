## 📋 标准化规范应用

### 1. **系统性应用规范**

| 数据类型 | 标准小数位数 | 适用范围 | 示例 |
|---------|------------|--------|------|
| **系数(Coefficient/Estimate)** | **3位** | Group, Age, Gender效应 | -1.090, 0.916, 0.087 |
| **标准误(SE)** | **3位** | 所有系数的标准误 | 0.087, 0.045 |
| **t值** | **2位** | t统计量 | 12.54, -3.21 |
| **P值** | **科学记数法** | 所有P值 | 7.66e-13, 2.49e-10, p<0.001 |
| **效应量(Cohen's d)** | **3位** | 所有效应量 | -0.545, 0.458, 0.381 |
| **R²** | **4位** | 模型拟合度 | 0.3108, 0.2686, 0.1948 |
| **相关系数(r)** | **3位** | Pearson/Spearman | -0.197, 0.453, 0.328 |
| **置信区间** | **3位** | 95% CI | [-1.234, -0.567] |
| **样本量(N)** | **整数** | 样本数 | 167, 111, 56 |

### 2. **P值处理规则**

```
规则1: p < 0.001 → 科学记数法 (e.g., 7.66e-13, 1.30e-08)
规则2: 0.001 ≤ p < 0.05 → 4位小数 (e.g., 0.0001, 0.0234, 0.0489)
规则3: p ≥ 0.05 → 3位小数 (e.g., 0.051, 0.234, 0.891)
```
