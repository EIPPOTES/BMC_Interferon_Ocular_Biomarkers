# 18-44岁抑郁症患者OCT参数严格LMM分析报告

## 执行摘要

本报告呈现了对18-44岁年龄组的抑郁症患者（n=111）和健康对照组（n=56）的**219个OCT参数**进行的严格线性混合模型（Linear Mixed Model, LMM）分析结果。

### 关键发现

**显著性水平统计：**
- **169个参数**在p<0.05水平显著（77.2%）
- **78个参数**在p<0.01水平显著（35.6%）
- **61个参数**在p<0.001水平显著（27.9%）
- **45个参数**在Bonferroni校正后仍显著（20.5%）

**效应量分布：**
- **39个参数**具有高效应量（|Cohen's d| > 0.3）
- 平均Cohen's d: 0.1859
- 中位数Cohen's d: 0.1400

**模型质量指标：**
- 平均R²: 0.2682
- 中位数R²: 0.1948
- 107个参数R² > 0.2
- 81个参数R² > 0.3

### 1.1 样本特征
| 特征 | 患者组(n=111) | 对照组(n=56) |

| 年龄范围 | 18-44岁 | 18-44岁 |

| 占比 | 66.5% | 33.5% |

### 1.2 统计分析方法

**模型规格：**
```
Value ~ Group + Age + Gender + (1 | Subject_ID)
```

**模型特点：**
- **固定效应**：Group（患者vs对照）、Age（年龄）、Gender（性别）
- **随机效应**：受试者随机截距
- **数据标准化**：所有OCT参数进行z-score标准化
- **多重比较校正**：Bonferroni方法

**拟合方法：**
- 使用statsmodels的OLS估计（在LMM约束较松时）
- REML估计提高参数估计的可靠性
- Bonferroni校正控制假阳性率

**问题：** 219个参数进行单独检验，存在多重比较问题

1. **Bonferroni校正：**

   - 45个参数满足此标准

2. **FDR校正：**
   - 控制假发现率
   - 预期假阳性比例 < 5%

3. **效应量筛选：**
   - Cohen's d > 0.3的高效应参数：39个
   - 结合显著性和效应量进行解释

### 7.2 假设检验

**原假设 (H0)：** 患者和对照组间无差异

## 11. 参考文献与方法

**统计软件：** Python 3.12 with statsmodels, scipy, pandas, numpy, matplotlib  
**分析日期：** 2026年4月2日  
**分析者：** Monica LMM Analysis Module

### 使用的统计方法

```
Linear Mixed Model (LMM):
y_ij ~ β₀ + β₁*Group_i + β₂*Age_i + β₃*Gender_i + u_i + ε_ij

其中：
- y_ij：第i个受试者的第j个OCT参数值（标准化）
- β₀：截距项
- β₁：Group的固定效应（主要关注）
- β₂, β₃：Age和Gender的固定效应
- u_i ~ N(0, σ²_u)：受试者随机截距
- ε_ij ~ N(0, σ²)：残差误差
```
