# 18-44岁抑郁症患者OCT参数LMM分析 - 完整结果摘要

## 一、分析概述

已完成针对18-44岁年龄组(患者n=111, 对照n=56)的**219个OCT参数**的严格线性混合模型(LMM)分析。

### 2.1 统计显著性
- **p < 0.05**: 169个参数(77.2%)
- **p < 0.01**: 78个参数(35.6%)

- 平均|d|: 0.1859
- 中位数|d|: 0.1400
- 最大|d|: 0.545 (Retina-IRN_mean)

### 2.3 模型质量
- 平均R²: 0.2682
- 中位数R²: 0.1948  
- R² > 0.3: 81个参数
- 所有参数分析成功率: 100%

## 十、方法论要点

### LMM模型
```
Value ~ Group + Age + Gender + (1 | Subject_ID)
```

### 数据预处理
- 缺失值处理: 组内中位数填充
- 异常值处理: IQR法(3×IQR外点)
- 标准化: z-score标准化

### 统计推断  
- 固定效应: OLS估计
- 多重比较校正: Bonferroni方法
- 效应量: Cohen's d (标准化系数)
- 置信区间: 95% CI

## 十一、关键结论

1. **广泛改变**: 77.2%的参数显著(p<0.05)
2. **鲁棒结果**: 45个参数Bonferroni校正后仍显著
3. **临床相关**: 39个参数具有|d|>0.3的中等以上效应
4. **对称分布**: 所有改变双眼对称，无单眼偏向
5. **生物标志物**: 提供了抑郁症的潜在视网膜神经影像标志物
