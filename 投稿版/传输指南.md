## 🚀 传输到Windows桌面的方法

### 方法1: 使用VSCode远程连接 (推荐)

如果您使用VSCode连接到此Linux环境：

1. **在VSCode中打开文件夹**:
   ```
   /root/.openclaw/workspace/投稿版
   ```

2. **右键点击文件夹** → **下载**

3. **保存到Windows桌面**:
   ```
   C:\Users\CUI\Desktop\投稿版
   ```

### 方法2: 使用SCP/SFTP

从Windows PowerShell或CMD：

```powershell
# 使用SCP复制整个目录
scp -r root@<linux-ip>:/root/.openclaw/workspace/投稿版 "C:\Users\CUI\Desktop\"

# 或使用SFTP客户端 (如FileZilla, WinSCP)
# 主机: <linux-ip>
# 用户名: root
# 密码: <您的密码>
# 远程路径: /root/.openclaw/workspace/投稿版
# 本地路径: C:\Users\CUI\Desktop\投稿版
```

### 方法3: 使用共享文件夹

如果Linux和Windows之间有共享文件夹：

```bash
# 在Linux中复制到共享文件夹
cp -r "/root/.openclaw/workspace/投稿版" /mnt/shared/

# 然后在Windows中从共享文件夹复制到桌面
```

### 方法4: 使用云存储

```bash
# 压缩文件
cd /root/.openclaw/workspace
tar -czvf 投稿版.tar.gz 投稿版/

# 上传到云存储 (如使用rclone)
rclone copy 投稿版.tar.gz <云存储>:/path/

# 然后在Windows下载并解压到桌面
```

### 方法5: 使用WSL (如果是WSL环境)

如果您在Windows WSL中运行：

```bash
# 直接复制到Windows桌面
cp -r "/root/.openclaw/workspace/投稿版" "/mnt/c/Users/CUI/Desktop/"
```
