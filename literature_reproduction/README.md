# 医学文献自主复现系统

## 系统概述
这是一个自动化系统，每天自主复现一篇医学文献（如meta分析、综述），建立系统化、可重复的文献复现流程。

## 设计理念
1. **自动化**：每天自动执行，无需人工干预
2. **系统化**：标准化的复现流程和质量控制
3. **透明化**：详细记录所有步骤和假设
4. **积累性**：每天优化流程，积累复现经验
5. **真实性**：只使用真实公开数据，严禁模拟数据

## 系统架构

### 定时任务
- **任务ID**: `e85e30b5-4ea6-44c4-b3d9-5fd8c6badc67`
- **执行频率**: 每天一次（24小时间隔）
- **执行模式**: 隔离会话（isolated session）
- **通知方式**: 执行完成后发送通知

### 技能库依赖
系统充分利用OpenClaw技能库：
1. **academic-research**: 文献检索（OpenAlex API）
2. **statistics-2 (pywayne-statistics)**: 统计分析（37+种测试方法）
3. **web-search**: 网络搜索，获取公开数据集
4. **pdf**: PDF文档分析，提取文献信息
5. **web-scraper**: 网页内容抓取，获取数据

## 复现流程

### 1. 文献检索与选择
- 搜索最新医学meta分析或系统综述
- 评估复现可行性
- 选择合适文献

### 2. 数据获取
- 查找公开数据集
- **只选择有公开数据的文献**，如无公开数据则跳过
- 数据真实性验证（来源权威性检查）
- 数据预处理

### 3. 方法提取
- 提取文献统计方法
- 明确分析流程

### 4. 分析复现
- 使用统计技能复现分析
- 记录参数设置

### 5. 结果验证
- 比较复现结果与原文
- 分析差异原因

### 6. 报告生成
- 创建标准化报告
- 保存到daily_reports目录

## 质量控制

### 复现标准
1. **数据真实性**：只使用真实公开数据，严禁模拟数据
2. **方法准确性**：严格遵循原文方法描述
3. **透明记录**：详细记录所有假设和步骤
4. **结果验证**：系统化比较复现结果
5. **局限说明**：明确标注复现局限性

### 错误处理
1. **数据不可用**：记录数据不可用情况，跳过该文献，选择其他有公开数据的文献
2. **方法不明确**：基于文献描述做出合理假设
3. **分析失败**：记录失败原因，继续流程

## 报告格式
