## 3. 方法提取与验证

### OCTolyzer 处理流程

```
输入 (.vol 文件)
    │
    ▼
┌──────────────────────────────────────┐
│  1. OCT B-scan 分割                   │
│     ├─ 黄斑区：Choroidalyzer          │
│     │   → 脉络膜区域 + 血管 + 中心凹   │
│     └─ 视盘周围：DeepGPET             │
│         → 脉络膜区域（不含血管分割）    │
│                                        │
│  2. SLO en face 分割                   │
│     ├─ 视网膜血管二值分割               │
│     ├─ 动静脉分类 + 视盘检测            │
│     └─ 中心凹检测                      │
│                                        │
│  3. 特征测量                           │
│     ├─ OCT：ETDRS网格区域测量           │
│     │   (1mm/3mm/6mm环形区域)          │
│     ├─ OCT：后极部8×8棋盘格              │
│     ├─ OCT：脉络膜厚度/血管指数         │
│     └─ SLO：血管形态学特征              │
└──────────────────────────────────────┘
    │
    ▼
输出 (分割结果 + 测量指标)
```

### 复现性验证

| 方法 | 复现性指标 | 结果 |
|------|-----------|------|
| 黄斑体积脉络膜厚度 | MAE / Pearson r | **6.7μm / 0.99** |
| 黄斑B-scan脉络膜厚度 | MAE / Pearson r | **11.6μm / 0.99** |
| 视盘周围脉络膜厚度 | MAE / Pearson r | **5.0μm / 0.99** |
| 黄斑体积CVI | MAE / Pearson r | **0.0271 / 0.97** |
| 黄斑B-scan CVI | MAE / Pearson r | **0.0130 / 0.91** |
| 区域/血管指标噪声 | 占人群变异的比例 | **<5% / <20%** |
| CPU处理时间(B-scan) | 单次处理 | **<3秒** |
| CPU处理时间(Volume) | 单次处理 | **<85秒** |

### 关键技术特点

1. **深度学习模型**: 使用U-Net架构的语义分割网络
2. **无需GPU**: 推理可在CPU上完成（但GPU加速可选）
3. **无需标注**: 完全自动化，无需人工干预
4. **错误修正**: 提供交互式调试模式和手动修正功能
5. **批量处理**: 通过 `main.py` 支持批量处理大量 .vol 文件

## 4. 与现有知识库关联分析

### 对崔医生OCT-MDD研究的直接价值

| 维度 | 关联点 | 价值评估 |
|------|--------|----------|
| **脉络膜分析** | MDD研究中脉络膜厚度的自动量化 | ⭐⭐⭐⭐⭐ 可直接替代手动分割 |
| **标准化测量** | ETDRS网格区域标准化输出 | ⭐⭐⭐⭐ 符合临床研究规范 |
| **复现性** | 高复现性（MAE < 12μm, r > 0.99） | ⭐⭐⭐⭐⭐ 增加结果可信度 |
| **重复分析** | 可批量处理OCT数据，实现完全可重复 | ⭐⭐⭐⭐⭐ 提升研究透明性 |
| **SLO血管分析** | 可提取en face视网膜血管特征 | ⭐⭐⭐ 若MDD研究涉及血管指标 |
| **软件集成** | Python API + Jupyter Notebook | ⭐⭐⭐⭐ 易于集成到分析流程 |

### 局限性

1. **.vol格式限制**: 若崔医生使用其他OCT设备（如Zeiss、Topcon），则需转换格式
2. **无正式出版**: 目前仅为预印本，尚未经同行评审验证
3. **依赖设备内置分割**: 视网膜层分割依赖Heidelberg设备内置软件，非独立算法
4. **脉络膜血管分割**: 视盘周围B-scan不支持脉络膜血管分割，仅限黄斑区

## 7. 操作建议

### 安装与试用步骤

```bash
# 克隆仓库
git clone https://github.com/jaburke166/OCTolyzer.git
cd OCTolyzer

# 创建Conda环境
conda create -n oct-analysis python=3.11 -y
conda activate oct-analysis
pip install -r requirements.txt

# 运行演示（使用demo目录下的示例数据）
jupyter notebook usage.ipynb
```

### 试用所需条件

- Heidelberg Spectralis OCT产生的 .vol 文件
- 至少一个测试数据集（建议来源于之前研究的原始OCT数据）
- Python 3.11 运行环境

1. OCTolyzer仍为预印本，正式发表前后可能出现代码更新或API变更

3. 个人OCT数据需注意患者隐私保护（.vol文件可能包含可识别信息）
