## 4. 方法提取与验证

### 文献 A 方法链

```
1. 数据预处理 → 眼底图像质量控制
2. 模型选择 → RETFound (自监督预训练foundation model)
3. 训练策略 → 5-fold cross-validation
   - 整体样本微调
   - 男性特异样本微调
   - 女性特异样本微调
4. 偏差校正 → 回归至均数偏差校正 (regression-to-the-mean bias correction)
5. 核心指标计算 → 视网膜年龄差距 (RAG) = 预测年龄 - 实际年龄
6. 关联分析 → RAG 与死亡率、痴呆症、CSVD、脑萎缩、血浆蛋白组学关联
```

### 文献 B 方法链

```
1. 系统检索 → PubMed, Embase, Web of Science
2. 纳入标准 → OCT 研究 + 焦虑/抑郁/物质使用障碍
3. 效应量 → Standardized Mean Difference (SMD)
4. 异质性评估 → I² 统计量
5. 亚组分析 → 按疾病类型、视网膜层类型分层
```

## 6. 结果对比与差异分析

### 主要发现对比

| 研究 | 核心发现 | 效应量 | 置信区间 |
|------|----------|--------|----------|
| **崔医生研究** | MDD组视网膜变薄（尤外层颞侧） | 未明确 | - |
| **文献 B (元分析)** | 病例组 vs 对照组无显著差异 | SMD = -0.20 | 95% CI [-0.53, 0.14] |
| **文献 A** | RAG 预测死亡/痴呆风险 | SHR = 1.25 | 95% CI 1.09-1.41 |

### 差异原因分析

1. **异质性来源**：元分析发现显著异质性 (I² 未报告)，不同研究间方法差异大
2. **样本特征**：崔医生研究为单中心，样本同质性较高；元分析汇总多中心数据
3. **扫描区域**：部分研究仅扫描黄斑区，部分包括视盘周围 RNFL
4. **疾病亚型**：MDD 严重程度、病程、用药状态可能影响结果
