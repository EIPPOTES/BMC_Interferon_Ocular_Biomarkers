## 4. 方法提取与验证

### 文献 A — TCCT-BP方法框架

**整体架构：**
```
OCT B-scan → CNN特征提取 → Cross-Convolution → Lightweight Transformer → 
Feature Grouping & Sampling → Polarization Loss → Boundary Regression → 
分层分割结果
```

**关键技术组件：**

| 组件 | 功能描述 | 创新点 |
|------|---------|--------|
| **CNN + Lightweight Transformer** | 混合架构同时捕获局部与全局特征 | 紧耦合Cross-Convolution设计，减少计算量同时保持大感受野 |
| **Boundary Regression** | 直接回归层间边界位置 | 不同于传统逐像素分割，从边界回归角度解决层间误差 |
| **Feature Polarization Loss** | 最大化不同视网膜层特征向量的区分度 | 特征分组采样 → 极化损失函数，增强特征判别性 |
| **Feature Grouping & Sampling** | 对各层特征进行分组和重采样 | 解决类不平衡问题（部分层厚度差异大） |

**训练配置：**
- 框架：PyTorch
- 损失函数：Polarization Loss + Boundary Regression Loss + Dice Loss（多任务）
- 评估指标：Dice系数、边界误差（mean absolute border error）、Hausdorff距离

**实验结果（GOALS数据集）：**
- 多层视网膜层分割Dice系数：各层均达到SOTA水平
- 边界误差显著低于对比方法
- 对视乳头周围OCT图像中的噪声、模糊和组织伪影具有良好鲁棒性
