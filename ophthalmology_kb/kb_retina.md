### 1.1 糖尿病视网膜病变 (Diabetic Retinopathy)

**AAO Preferred Practice Pattern® (2019)**

| 指标 | 内容 |
|------|------|
| 引用次数 | 671 |
| 期刊 | Ophthalmology |
| DOI | 10.1016/j.ophtha.2019.09.025 |
| 开放获取 | ❌ (需订阅) |

**核心要点**:
- 筛查间隔: 1型糖尿病确诊5年后开始筛查，2型糖尿病确诊时即开始筛查
- 分期标准: 非增殖期(NPDR) vs 增殖期(PDR)
- 治疗指征: 高危PDR、临床显著黄斑水肿(CSME)
- 抗VEGF治疗: 糖尿病黄斑水肿(DME)的一线治疗

**来源验证**: DOI: 10.1016/j.ophtha.2019.09.025 (通过OpenAlex验证有效)

### 1.2 年龄相关性黄斑变性 (AMD)

**AAO Preferred Practice Pattern® (2019)**

| 指标 | 内容 |
|------|------|
| 引用次数 | 331 |
| 期刊 | Ophthalmology |
| DOI | 10.1016/j.ophtha.2019.09.024 |
| 开放获取 | ❌ (需订阅) |

**分期标准**:

| 分期 | 特征 |
|------|------|
| 早期AMD | 玻璃膜疣 (直径>125μm) 但无色素沉着异常 |
| 中期AMD | 广泛玻璃膜疣 (直径>125μm) + 色素异常 |
| 晚期AMD | 地图样萎缩 或 新生血管性AMD |

**治疗**:
- 新生血管性AMD: 抗VEGF治疗 (雷珠单抗、阿柏西普、康柏西普)
- Pegaptanib: 首个获批的抗VEGF药物

**Pegaptanib经典研究**:
- 发表: New England Journal of Medicine, 2004
- 引用: 2308次
- DOI: 10.1056/nejmoa042760
- URL: https://www.nejm.org/doi/pdf/10.1056/NEJMoa042760
- 开放获取: ✅

## 二、糖尿病视网膜病变流行病学

### 2.1 全球流行病学数据

**来源**: Epidemiology of diabetic retinopathy, diabetic macular edema and related vision loss (2015)
- 期刊: Eye and Vision
- 引用: 1535次
- DOI: 10.1186/s40662-015-0026-2
- URL: https://eandv.biomedcentral.com/track/pdf/10.1186/s40662-015-0026-2
- 开放获取: ✅

**关键数据**:
- 全球糖尿病患者约2.85亿
- 约1/3有DR表现
- 其中1/3为威胁视力的DR (包括DME)

### 2.2 深度学习在DR筛查中的应用

**DLS研究**:
- 标题: Development and Validation of a Deep Learning System for Diabetic Retinopathy
- 期刊: JAMA, 2017
- 引用: 2215次
- DOI: 10.1001/jama.2017.18152
- URL: https://jamanetwork.com/journals/jama/articlepdf/2665775/jama_ting_2017_oi_170140.pdf

**主要发现**:
