# 眼科专业知识知识库

## 简介

本知识库系统整理了眼科权威临床指南和研究文献，严格遵循真实性要求，所有资料均来自权威学术来源。

## 构建原则

### 1. 真实性承诺
- ✅ 所有资料来源可验证
- ✅ 优先使用学术数据库
- ✅ 标注完整DOI和引用信息
- ✅ 拒绝非权威或来源不明信息

### 2. 来源类型
- AAO Preferred Practice Patterns
- 欧洲眼科学会指南
- 顶级期刊文献 (NEJM, Lancet, Nature, JAMA, Ophthalmology等)
- 高引用经典研究

### 3. 验证机制
- OpenAlex API DOI验证
- 开放获取状态确认
- 期刊权威性检查
