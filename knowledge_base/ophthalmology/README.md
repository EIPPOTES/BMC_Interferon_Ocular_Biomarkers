- 系统性综述和Meta分析

## 真实性验证记录

### 验证方法
1. 所有文献通过OpenAlex API检索
2. 验证DOI可访问性
3. 优先选择开放获取（Open Access）文献
4. 记录引用次数作为影响力指标
5. 标注出版年份确保时效性

### 来源权威性分级
- **A级**: AAO PPP指南、国际学会官方指南
- **B级**: 高影响因子期刊（Ophthalmology, JAMA Ophthalmology等）
- **C级**: 系统性综述和Meta分析
- **D级**: 其他同行评议研究
