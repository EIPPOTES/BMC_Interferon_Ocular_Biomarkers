## 1. 标准正态分布表 (Z表)

### 基本概念
- **标准正态分布**: 均值为0，标准差为1的正态分布
- **Z分数**: 表示一个值距离均值有多少个标准差
  ```
  Z = (X - μ) / σ
  ```

### Z表的类型
1. **累积分布表 (Cumulative from -∞ to Z)**
   - 表示 P(Z ≤ z)，即从负无穷到z的累积概率
   - 最常用类型

2. **累积分布表 (Cumulative, less than Z)**
   - 同上，只是表述方式不同

3. **互补累积分布表 (Complementary cumulative)**
   - 表示 P(Z > z) = 1 - P(Z ≤ z)
   - 用于单侧检验

### 眼科研究中的应用
- 计算百分位数（如视力分布的第95百分位）
- 假设检验中的p值计算
- 样本量计算

## 2. t分布 (Student's t-distribution)

### 基本参数
| 参数 | 说明 |
|------|------|
| 自由度 (ν) | 决定分布形状，ν > 0 |
| 均值 | 0 (当ν > 1时) |
| 方差 | ν/(ν-2) (当ν > 2时) |
| 形态 | 钟形，比正态分布更扁平，尾部更厚 |

### 关键特性
- 当自由度ν → ∞时，t分布趋近于标准正态分布
- 小样本时，t分布比正态分布更保守（置信区间更宽）

### 眼科研究中的应用
- **小样本均数比较**: n < 30时使用t检验而非Z检验
- **配对t检验**: 比较治疗前后视力变化
- **独立样本t检验**: 比较两组患者的OCT参数

### R代码示例
```r
# 计算t临界值 (双尾检验, α=0.05, df=20)
qt(0.975, df=20)  # 返回 2.086

# 计算p值
t_stat <- 2.5
pt(t_stat, df=20, lower.tail=FALSE) * 2  # 双尾p值
```

## 3. 卡方分布 (Chi-squared distribution)

### 基本参数
| 参数 | 说明 |
|------|------|
| 自由度 (k) | 决定分布形状，k ∈ ℕ⁺ |
| 均值 | k |
| 方差 | 2k |
| 众数 | max(k-2, 0) |
| 支持域 | x ∈ (0, +∞) |

### 概率密度函数
```
f(x; k) = (1 / (2^(k/2) * Γ(k/2))) * x^((k/2)-1) * e^(-x/2)
```

### 眼科研究中的应用
- **卡方检验**: 比较分类变量（如性别、疾病分期）
- **拟合优度检验**: 检验观察值是否符合预期分布
- **独立性检验**: 检验两个分类变量是否独立

### R代码示例
```r
# 计算卡方临界值 (α=0.05, df=1)
qchisq(0.95, df=1)  # 返回 3.841

# 卡方检验
observed <- c(30, 20)  # 观察值
expected <- c(25, 25)  # 期望值
chisq.test(rbind(observed, expected))
```

## 4. F分布 (F-distribution)

### 基本特性
- 两个独立的卡方分布变量之比
- 有两个自由度参数：df1 (分子), df2 (分母)
- 非负分布，右偏

### 定义
如果 U ~ χ²(df1) 和 V ~ χ²(df2) 独立，则：
```
F = (U/df1) / (V/df2) ~ F(df1, df2)
```

### 眼科研究中的应用
- **方差分析 (ANOVA)**: 比较多组均数
- **回归分析**: 检验整体模型显著性
- **两组方差比较**: F检验

### R代码示例
```r
# 计算F临界值 (α=0.05, df1=2, df2=30)
qf(0.95, df1=2, df2=30)  # 返回 3.316

# 单因素方差分析
aov_result <- aov(BCVA ~ treatment_group, data=df)
summary(aov_result)
```

## 5. 眼科研究中的统计表格速查

### 常用临界值表

#### Z分布 (标准正态)
| 置信水平 | 双尾临界值 | 单尾临界值 |
|---------|-----------|-----------|
| 90% | 1.645 | 1.282 |
| 95% | 1.960 | 1.645 |
| 99% | 2.576 | 2.326 |

#### t分布 (df=∞时趋近Z值)
| 自由度 | 95%双尾 | 99%双尾 |
|-------|--------|--------|
| 10 | 2.228 | 3.169 |
| 20 | 2.086 | 2.845 |
| 30 | 2.042 | 2.750 |
| ∞ | 1.960 | 2.576 |

### 样本量估算常用公式

#### 两均数比较
```
n = 2 * [(Zα/2 + Zβ)² * σ²] / δ²
```
- σ: 标准差
- δ: 期望检测的组间差异
- Zα/2: 显著性水平对应的Z值
- Zβ: 把握度对应的Z值

#### 两率比较
```
n = [Zα/2√(2p̄(1-p̄)) + Zβ√(p1(1-p1)+p2(1-p2))]² / (p1-p2)²
```
