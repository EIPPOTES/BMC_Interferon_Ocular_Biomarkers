## t检验验证：与"丽"的分析对比 (09:33)

### 实验设计
- 目的：验证使用t检验是否得到与"丽"相似的结果
- 方法：独立样本t检验 (scipy.stats.ttest_ind)

### 结果对比

| 统计方法 | 显著参数数量(P<0.05) |
|---------|---------------------|
| 我们的LMM | 5个 |
| 我们的t检验 | 15个 |
| "丽"的t检验 | ~30个 |

### 关键参数对比 (t检验)

| 参数 | 我们的P值 | 丽的结果 | 一致性 |
|------|-----------|----------|--------|
| Retina_内环上方 | 0.004 ✓ | <0.05 ✓ | ✅ |
| Retina_内环颞侧 | 0.010 ✓ | <0.05 ✓ | ✅ |
| Retina_外环上方 | 0.001 ✓ | <0.05 ✓ | ✅ |
| Retina_外环鼻侧 | 0.167 | <0.05 | ❌ |
| GCL++_外环上方 | 0.004 ✓ | <0.05 ✓ | ✅ |

### 结论
1. t检验确实能重现"丽"的部分结果（一致性约60%）
2. LMM比t检验更保守（5 vs 15个显著参数）
3. 差异原因：样本量不同（301眼 vs 179人），数据清洗方式不同
