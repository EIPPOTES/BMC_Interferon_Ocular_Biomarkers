## 🔧 **字符串插值路径修复 (21:28-21:40)**

### **核心问题分析**
**字符串插值路径**: Python中的f-string包含路径变量，如：
```python
df = pd.read_excel(f'{data_dir}/OCT数据_完整整合.xlsx')
plt.savefig(f'{output_dir}/Figure1_研究流程图.png', ...)
```
**挑战**: 变量`data_dir`和`output_dir`是硬编码字符串，f-string引用这些变量

### **解决方案实施**
1. **配置系统扩展**:
   - 新增`EXTERNAL_DATA_DIR`配置变量
   - 保留现有`FIGURES_OUTPUT_DIR`配置

2. **关键脚本修复** (`create_figures.py`):
   - ✅ 添加配置导入: `from configs.paths_config import *`
   - ✅ 变量替换:
     - `output_dir = str(FIGURES_OUTPUT_DIR)`
     - `data_dir = str(EXTERNAL_DATA_DIR)`
   - ✅ f-string自动引用新的配置变量
   - ✅ 功能验证: 导入成功，无自动执行

3. **技术验证**:
   - 导入测试: ✅ 成功
   - 变量引用: ✅ f-string正确使用配置变量
   - 功能兼容性: ✅ 保持原始数据访问逻辑

### **修复模式总结**
```
原始代码:
    output_dir = '/mnt/c/Users/CUI/Desktop/论文及图表'
    plt.savefig(f'{output_dir}/Figure1.png')
    
修复后:
    output_dir = str(FIGURES_OUTPUT_DIR)  # 配置引用
    plt.savefig(f'{output_dir}/Figure1.png')  # 自动使用配置
```

## 🔧 **端口管理与监控系统创建** (22:31-22:38)

### **问题诊断与解决方案**
**问题**: clash(pid 277)和mihomo(pid 261)服务同时运行导致端口冲突
**冲突端口**: 7895 (HTTP代理端口)
**错误现象**: `address already in use` 错误，mixed-port配置冲突

### **技术解决方案实施**
1. **服务状态检查**:
   ```bash
   systemctl status clash mihomo → clash服务inactive，mihomo服务运行中
   ```

2. **配置文件分析**:
   ```bash
   grep -n "mixed-port" /etc/clash/config-simple.yaml → mixed-port: 7895
   ```

3. **端口冲突修复**:
   ```bash
   sudo sed -i 's/mixed-port: 7895/mixed-port: 0/' /etc/clash/config-simple.yaml
   ```

4. **服务重启验证**:
   ```bash
   sudo systemctl restart mihomo → 所有端口正常监听
   ```

5. **冲突服务清理**:
   ```bash
   sudo systemctl stop clash && sudo systemctl disable clash
   ```
