### 14. LMM混合效应模型解释

**比喻**: 研究同一家庭的孩子身高，不能把每个孩子当作独立个体，需要把"家庭"作为随机效应。

**我们的模型**:
```
Retina厚度 ~ 分组 + 年龄 + 性别 + (1|患者ID)
                        ↑        ↑     ↑
                    固定效应  协变量  随机效应
```

- 随机效应(患者ID): 正确处理双眼相关性
- 固定效应(分组): MDD vs 对照的主要效应
- 协变量(年龄+性别): 控制混杂因素

✅ LMM运用完全正确，是眼科双边数据的金标准方法
