# 医学文献写作指南

*学习来源: Wikipedia | 学习时间: 2026-03-07*
*针对: 眼科科研论文写作*

---

## 第一部分: 科学写作基础

### 1. 科学写作的定义与特点

**定义**: 科学家为同行撰写的关于科学研究的专门技术写作

**核心特点**:
- **客观性**: 基于事实和数据，避免主观臆断
- **精确性**: 使用准确的术语和量化描述
- **可重复性**: 提供足够细节使研究可重复
- **逻辑性**: 结构清晰，论证严密

**与科普写作的区别**:

| 特征 | 科学写作 | 科普写作 |
|------|---------|---------|
| 目标读者 | 专业同行 | 普通公众 |
| 语言风格 | 技术性强 | 通俗易懂 |
| 内容深度 | 详细完整 | 简化概述 |
| 术语使用 | 专业术语 | 解释术语 |

### 2. 学术诚信

**抄袭 (Plagiarism)**:
- 将他人的语言、思想、观点或表达作为自己的原创作品
- 严重违反学术道德，可能导致撤稿、学术处分

**避免抄袭的方法**:
1. **正确引用**: 所有非原创观点必须标注来源
2. **适当改写**: 理解后用自己的语言重新表达
3. **使用引号**: 直接引用时加引号并注明出处
4. **查重工具**: 投稿前使用Turnitin、iThenticate等检查

**引用规范**:
- **Vancouver格式**: 医学期刊常用，数字上标
- **APA格式**: 社会科学常用，作者-年份
- **MLA格式**: 人文学科常用

## 第二部分: IMRAD结构详解

### 1. IMRAD概述

**定义**: Introduction (引言), Methods (方法), Results (结果), And Discussion (讨论) 的标准论文结构

**"酒杯模型" (Wineglass Model)**:
- 顶部宽 (引言): 从宏观到具体
- 中部窄 (方法/结果): 聚焦研究核心
- 底部宽 (讨论): 从具体到宏观

### 2. 引言 (Introduction)

**功能**: 回答"为什么做这项研究"

**结构 (倒金字塔)**:
```
1. 研究背景 (最宏观)
   ↓
2. 文献综述
   ↓
3. 研究空白/问题
   ↓
4. 研究目的/假设 (最具体)
```

**写作要点**:
- 从已知到未知
- 逻辑递进，层层深入
- 最后明确提出研究问题
- 避免冗长，通常1-2页

**眼科论文示例结构**:
```
1. AMD是老年人视力丧失的主要原因 [背景]
2. 抗VEGF治疗显著改善视力 [已知]
3. 但最佳治疗间隔仍不明确 [问题]
4. 本研究比较PRN与T&E方案 [目的]
```

### 3. 方法 (Methods)

**功能**: 回答"如何做这项研究"

**核心内容**:

#### 3.1 研究设计
- 研究类型 (RCT、队列、病例对照等)
- 研究地点和时间
- 伦理审批和知情同意

#### 3.2 研究对象
- 纳入标准
- 排除标准
- 样本量计算

#### 3.3 干预/暴露
- 治疗方案详细描述
- 剂量、频率、持续时间

#### 3.4 结局指标
- 主要结局
- 次要结局
- 测量方法和时间点

#### 3.5 统计分析
- 统计软件
- 统计方法
- 显著性水平

**写作要点**:
- 详细到可重复
- 使用过去时态
- 避免结果混入

**眼科研究特殊报告**:
- 视力测量方法 (Snellen/LogMAR)
- OCT设备型号和软件版本
- 影像判读标准
- 双眼数据处理方案

### 4. 结果 (Results)

**功能**: 回答"发现了什么"

**结构**:
1. **研究流程图**: CONSORT流程图
2. **基线特征**: 人口学和临床特征
3. **主要结果**: 按重要性排序
4. **次要结果**: 亚组分析、敏感性分析
5. **不良事件**: 安全性数据

**写作要点**:
- 客观陈述，不解释
- 图表优先，文字补充
- 报告精确数值和置信区间
- 避免重复图表内容

**统计报告规范**:
```
✅ 正确: "治疗组BCVA改善5.2个字母 (95% CI: 3.1-7.3, P<0.001)"
❌ 错误: "治疗组视力明显改善 (P<0.05)"
```

### 5. 讨论 (Discussion)

**功能**: 回答"发现意味着什么"

**结构 (正金字塔)**:
```
1. 主要发现总结 (最具体)
   ↓
2. 与既往研究比较
   ↓
3. 研究意义
   ↓
4. 局限性
   ↓
5. 结论和展望 (最宏观)
```

**各段落要点**:

**第一段 - 研究总结**:
- 简洁概括主要发现
- 直接回答研究问题

**第二段 - 结果解释**:
- 与现有文献比较
- 解释一致或不一致的原因
- 讨论机制

**第三段 - 临床意义**:
- 对临床实践的影响
- 对指南制定的意义

**第四段 - 研究局限性**:
- 诚实承认不足
- 说明对结果的影响
- 避免过度辩护

**第五段 - 结论**:
- 简明扼要
- 避免过度推断
- 提出未来研究方向

**写作技巧**:
- 使用主动语态增强说服力
- "我们的研究发现..."比"研究发现..."更有力
- 避免"首次报道"等绝对表述

## 第三部分: 摘要写作

### 1. 摘要类型

**结构式摘要** (Structured Abstract):
- 目的 (Objective)
- 方法 (Methods)
- 结果 (Results)
- 结论 (Conclusion)

**非结构式摘要**:
- 连续段落
- 包含相同要素

### 2. 摘要写作原则

**字数限制**:
- 多数期刊: 250-300词
- 部分期刊: 150词 (Brief Report)

**关键原则**:
1. **独立性**: 不读全文也能理解
2. **完整性**: 包含研究核心要素
3. **准确性**: 与正文一致
4. **简洁性**: 无冗余信息

### 3. 各要素写作要点

**目的 (1-2句)**:
- 研究背景 (1句)
- 研究目的/假设 (1句)

**方法 (2-4句)**:
- 研究设计
- 研究对象
- 干预/暴露
- 主要结局指标

**结果 (3-5句)**:
- 主要发现 (带具体数值)
- 关键次要发现
- 不良事件 (如相关)

**结论 (1-2句)**:
- 主要结论
- 临床意义

### 4. 摘要示例 (眼科RCT)

```
目的: 比较雷珠单抗治疗-延长(T&E)方案与按需(PRN)方案治疗糖尿病黄斑水肿(DME)的疗效和安全性。

方法: 多中心、随机、对照试验。纳入视力20/40-20/320的DME患者，随机分配至T&E组(n=150)或PRN组(n=150)。
主要结局为12个月时最佳矫正视力(BCVA)变化。

结果: 12个月时，T&E组BCVA改善8.5±5.2个字母，PRN组改善5.3±6.1个字母(差异3.2字母，95% CI: 1.5-4.9，P<0.001)。
T&E组平均注射次数8.2次，PRN组6.5次。两组严重不良事件发生率相似(5.3% vs 4.7%)。

结论: T&E方案较PRN方案视力改善更显著，虽注射次数略多，但可减少随访频率。T&E可作为DME的一线治疗方案。
```

## 第四部分: 文献综述

### 1. 综述类型

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| **叙述性综述** | 描述性，无系统方法 | 新领域概述 |
| **系统性综述** | 系统检索，严格方法 | 证据综合 |
| **Meta分析** | 定量合并数据 | 有足够RCT |
| **范围综述** | 绘制研究地图 | 领域概览 |

### 2. 系统性综述步骤

1. **制定研究问题** (PICO框架)
   - P: Population (人群)
   - I: Intervention (干预)
   - C: Comparison (对照)
   - O: Outcome (结局)

2. **制定纳入排除标准**

3. **系统检索**
   - 多个数据库 (PubMed, Embase, Cochrane)
   - 检索策略
   - 灰色文献

4. **筛选文献**
   - 双人独立筛选
   - 记录排除原因

5. **质量评估**
   - RCT: Cochrane Risk of Bias工具
   - 观察性研究: Newcastle-Ottawa Scale

6. **数据提取**

7. **综合分析**
   - 定性综合
   - 定量合并 (Meta分析)

8. **撰写报告**
   - PRISMA声明

### 3. PRISMA声明

**Preferred Reporting Items for Systematic Reviews and Meta-Analyses**

**核心要素**:
- 标题标识
- 结构化摘要
- 引言 (理论基础、目的)
- 方法 (方案、纳入标准、信息来源、检索、研究选择、数据提取、研究质量、合成方法)
- 结果 (检索结果、研究特征、单个研究结果、合成结果、报告偏倚、敏感性分析)
- 讨论 (证据总结、局限性、结论)
- 资金

## 第五部分: 同行评审

### 1. 同行评审流程

```
投稿 → 编辑初审 → 送审 → 专家评审 → 决定
                      ↓
              大修/小修/拒稿/接受
```

### 2. 评审类型

| 类型 | 特点 | 优缺点 |
|------|------|--------|
| **单盲** | 审稿人知道作者 | 最常见 |
| **双盲** | 双方互不知晓 | 减少偏见 |
| **开放** | 公开审稿人身份 | 透明但可能有顾虑 |

### 3. 常见审稿意见类型

**拒稿原因**:
- 创新性不足
- 研究设计缺陷
- 样本量不足
- 统计方法错误
- 写作质量差

**修改建议**:
- 补充分析
- 澄清方法
- 加强讨论
- 语言润色

### 4. 回复审稿意见技巧

**原则**:
1. **逐条回复**: 每个意见都回应
2. **礼貌尊重**: 即使不同意也要礼貌
3. **具体明确**: 说明修改位置和内容
4. **标记修改**: 在正文中高亮修改处

**回复格式**:
```
审稿意见1: ...
回复: 感谢审稿人的建议。我们已在方法部分第2段补充了样本量计算的详细过程(第3页，第15-20行)。

审稿意见2: ...
回复: 我们不同意这一观点，原因是... (提供证据)。原文未做修改。
```

## 第六部分: 论文类型与投稿

### 1. 主要论文类型

| 类型 | 特点 | 字数 | 适用 |
|------|------|------|------|
| **Original Article** | 完整研究 | 3000-5000词 | 主要研究发现 |
| **Brief Report** | 简短报道 | 1500-2500词 | 初步结果 |
| **Case Report** | 病例报告 | 1000-2000词 | 罕见病例 |
| **Review** | 综述 | 4000-8000词 | 领域总结 |
| **Letter** | 通讯 | 500-1000词 | 评论/快速交流 |
| **Editorial** | 社论 | 邀请撰写 | 观点表达 |

### 2. 眼科期刊分级

**顶级期刊 (IF > 10)**:
- JAMA Ophthalmology
- The Lancet Digital Health (眼科AI)

**一流期刊 (IF 5-10)**:
- Ophthalmology
- Retina
- IOVS
- British Journal of Ophthalmology

**二流期刊 (IF 2-5)**:
- Eye
- Graefe's Archive
- American Journal of Ophthalmology

**专业期刊**:
- Ophthalmology Retina
- Asia-Pacific Journal of Ophthalmology

### 3. 投稿策略

**选择期刊考虑因素**:
1. 研究主题匹配度
2. 影响因子和声誉
3. 审稿周期
4. 开放获取政策
5. 接受率

## 第七部分: 写作技巧与常见错误

### 1. 语言风格

**时态使用**:

| 部分 | 时态 | 示例 |
|------|------|------|
| 引言 | 现在时/现在完成时 | "AMD is...", "Several studies have shown..." |
| 方法 | 过去时 | "We enrolled...", "Patients were randomized..." |
| 结果 | 过去时 | "BCVA improved...", "The mean difference was..." |
| 讨论 | 现在时/过去时 | "Our findings suggest...", "We found that..." |

**语态选择**:
- 传统: 被动语态 (强调研究本身)
- 现代趋势: 主动语态 (更简洁有力)

```
被动: "The patients were enrolled by the investigators."
主动: "We enrolled the patients."
```

### 2. 常见错误

**统计报告错误**:
- ❌ "P=0.00" → ✅ "P<0.001"
- ❌ "无显著差异" → ✅ "差异无统计学意义"
- ❌ 仅报告P值 → ✅ 报告效应量和CI

**语言错误**:
- ❌ "very significant" → ✅ "statistically significant"
- ❌ "prove" → ✅ "suggest/indicate"
- ❌ "the first study" → ✅ "to our knowledge, the first study"

**结构错误**:
- 结果中解释发现
- 讨论中报告新数据
- 引言过长或过短

### 3. 写作工具推荐

**语言润色**:

## 第八部分: 眼科论文特殊考虑

### 1. 影像报告规范

**OCT报告**:
- 设备型号和软件版本
- 扫描协议 (如 cube 6×6 mm)
- 测量参数定义
- 质量控制标准

**眼底照片**:
- 相机型号
- 视野角度 (如 30°, 45°)
- 图像增强处理说明

### 2. 视力报告

**标准格式**:
```
BCVA (LogMAR) = X.XX ± X.XX (Snellen equivalent: 20/XX)
```

**转换表**:
| Snellen | LogMAR |
|---------|--------|
| 20/20 | 0.0 |
| 20/40 | 0.3 |
| 20/80 | 0.6 |
| 20/200 | 1.0 |

### 3. 双眼数据处理

**报告规范**:
- 说明分析单位 (眼 vs 患者)
- 如按眼分析，说明如何处理双眼
- 如按患者，说明选择哪只眼或如何平均

**推荐表述**:
```
"Because the eyes of the same patient are likely to be 
correlated, we used linear mixed-effects models with 
random intercepts for patients to account for the 
correlation between eyes."
```
