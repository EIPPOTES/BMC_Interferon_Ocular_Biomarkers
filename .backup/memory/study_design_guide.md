## 第一部分: 研究设计类型总览

### 1. 研究设计分类

```
医学研究
├── 实验性研究 (Experimental)
│   ├── 随机对照试验 (RCT)
│   ├── 交叉试验 (Crossover)
│   └── 析因设计 (Factorial)
│
└── 观察性研究 (Observational)
    ├── 描述性研究
    │   ├── 横断面研究 (Cross-sectional)
    │   └── 病例报告 (Case Report)
    └── 分析性研究
        ├── 队列研究 (Cohort)
        ├── 病例对照研究 (Case-control)
        └── 生态学研究 (Ecological)
```

### 2. 证据等级金字塔

```
        Meta分析
           ↑
      随机对照试验 (RCT)
           ↑
       队列研究
           ↑
    病例对照研究
           ↑
     横断面研究
           ↑
      病例报告
```

## 第二部分: 实验性研究设计

### 1. 随机对照试验 (Randomized Controlled Trial, RCT)

**定义**: 将研究对象随机分配到干预组和对照组，比较干预效果的实验性研究

**核心特征**:
- **随机化 (Randomization)**: 消除选择偏倚
- **对照 (Control)**: 提供比较基准
- **盲法 (Blinding)**: 减少测量偏倚

#### 1.1 随机化方法

| 方法 | 说明 | 适用场景 |
|------|------|---------|
| **简单随机化** | 抛硬币/随机数字 | 大样本研究 |
| **区组随机化** | 每n个为一区组随机 | 保证组间平衡 |
| **分层随机化** | 按重要预后因素分层 | 存在重要混杂因素 |
| **最小化法** | 动态平衡各组基线 | 小样本研究 |

**R代码示例**:
```r
# 简单随机化
set.seed(123)
n <- 100
group <- sample(c("Treatment", "Control"), n, replace=TRUE)

# 区组随机化 (区组大小为4)
library(blockrand)
rand <- blockrand(n=100, num.levels=2, block.sizes=2)

# 分层随机化
# 按疾病严重程度分层
strata <- data.frame(
  severity = rep(c("Mild", "Moderate", "Severe"), each=40)
)
strata$group <- ave(strata$severity, strata$severity, 
                    FUN=function(x) sample(c("A", "B"), length(x), replace=TRUE))
```

#### 1.2 对照类型

| 对照类型 | 说明 | 示例 |
|---------|------|------|
| **安慰剂对照** | 使用无活性物质 | 口服药片试验 |
| **阳性对照** | 使用已知有效药物 | 新药vs标准治疗 |
| **剂量对照** | 不同剂量比较 | 高剂量vs低剂量 |
| **历史对照** | 与既往数据比较 | 罕见病研究 |
| **自身对照** | 同一对象前后比较 | 交叉设计 |

#### 1.3 盲法设计

| 盲法类型 | 说明 | 偏倚控制 |
|---------|------|---------|
| **开放标签** | 所有人均知分组 | 无 |
| **单盲** | 患者不知分组 | 减少安慰剂效应 |
| **双盲** | 患者和研究者均不知 | 减少观察偏倚 |
| **三盲** | 患者、研究者、统计师均不知 | 最严格 |

**眼科研究的盲法挑战**:
- 手术试验难以盲患者
- 玻璃体腔注射有明显副作用
- 解决方案: 盲终点评估者

#### 1.4 RCT设计变体

**平行组设计 (Parallel Group)**:
```
患者 → 随机分组
      ├── 治疗组 → 随访 → 结局
      └── 对照组 → 随访 → 结局
```

**交叉设计 (Crossover)**:
```
患者 → 随机分组
      ├── A组: 治疗A → 洗脱期 → 治疗B
      └── B组: 治疗B → 洗脱期 → 治疗A
```
- **优点**: 自身对照，减少个体差异
- **缺点**: 需稳定疾病，有残留效应风险
- **适用**: 慢性稳定疾病 (如干眼症)

**析因设计 (Factorial)**:
```
          因素B
       有      无
因  有  A+B     A
素  无  B      安慰剂
A
```
- **优点**: 同时研究多个因素，检测交互作用
- **适用**: 评估联合治疗

### 2. 临床试验分期

| 分期 | 目的 | 样本量 | 设计 |
|------|------|--------|------|
| **I期** | 安全性、耐受性、剂量 | 20-80 | 开放、剂量递增 |
| **II期** | 初步疗效、进一步安全性 | 100-300 | 单臂或RCT |
| **III期** | 确证疗效、监测不良反应 | 数百-数千 | 多中心RCT |
| **IV期** | 上市后监测 | 大量 | 观察性研究 |

## 第三部分: 观察性研究设计

### 1. 队列研究 (Cohort Study)

**定义**: 根据是否暴露于某因素分组，随访观察结局发生情况

**类型**:
- **前瞻性队列**: 从现在开始随访
- **回顾性队列**: 利用既往数据随访
- **双向队列**: 结合前瞻和回顾

**设计示意图**:
```
现在                    将来
↓                        ↓
暴露组 ───────────────→ 发病
非暴露组 ─────────────→ 发病
```

**关键指标**:
- **发病率 (Incidence)**: 新发病例/人时
- **相对危险度 (RR)**: 暴露组发病率/非暴露组发病率
- **归因危险度 (AR)**: 暴露组发病率 - 非暴露组发病率

**优点**:
- 可计算发病率和RR
- 可研究多种结局
- 暴露先于结局，因果时序明确

**缺点**:
- 耗时、昂贵
- 不适用于罕见病
- 失访偏倚

**眼科应用**:
- 高度近视与黄斑病变关系
- 糖尿病病程与DR进展
- 眼压与青光眼发病

**R代码示例**:
```r
# 队列研究分析
library(survival)

# 创建生存对象
surv_obj <- Surv(time=follow_up_time, event=disease_occurred)

# Cox比例风险模型
cox_model <- coxph(surv_obj ~ exposure + age + gender, data=cohort_data)
summary(cox_model)

# 计算累积发病率
km_fit <- survfit(surv_obj ~ exposure, data=cohort_data)
plot(km_fit, xlab="Time (years)", ylab="Disease-free Survival")
```

### 2. 病例对照研究 (Case-Control Study)

**定义**: 选择患有某病的病例组和未患病的对照组，回顾性比较暴露史

**设计示意图**:
```
现在
↓
病例组 ──┐
         ├──→ 回顾暴露史
对照组 ──┘
```

**关键指标**:
- **比值比 (OR)**: 病例组暴露比值/对照组暴露比值
- OR ≈ RR (当疾病罕见时)

**优点**:
- 快速、经济
- 适用于罕见病
- 可同时研究多种暴露因素

**缺点**:
- 无法计算发病率
- 回忆偏倚
- 选择对照困难

**对照选择原则**:
1. 来自同一源人群
2. 独立于暴露因素
3. 能代表源人群

**匹配 (Matching)**:
- **目的**: 控制混杂因素
- **方法**: 按年龄、性别等配对
- **注意**: 过度匹配会低估效应

**眼科应用**:
- AMD危险因素研究
- 青光眼家族史研究
- 药物与眼部副作用

**R代码示例**:
```r
# 病例对照研究分析
# 计算OR和95%CI
library(epitools)

# 2×2表
#        暴露  非暴露
# 病例    a      b
# 对照    c      d

or_result <- oddsratio(matrix(c(a, b, c, d), nrow=2))
print(or_result)

# Logistic回归
model <- glm(case ~ exposure + age + gender, 
             family=binomial(link="logit"), 
             data=case_control_data)
exp(cbind(coef(model), confint(model)))
```

### 3. 横断面研究 (Cross-Sectional Study)

**定义**: 在特定时间点收集暴露和结局数据

**特点**:
- **时点患病率**: 某时点现存病例/调查人口
- 暴露和结局同时测量
- 无法确定因果时序

**优点**:
- 快速、经济
- 适用于描述疾病负担
- 可产生病因假设

**缺点**:
- 无法确定时间顺序
- 患病率偏倚 (病程长的病例被过度代表)

**眼科应用**:
- 全国眼病流行病学调查
- 糖尿病视网膜病变患病率
- 近视患病率调查

## 第四部分: 研究设计选择指南

### 1. 根据研究问题选择设计

| 研究问题 | 推荐设计 | 替代设计 |
|---------|---------|---------|
| 治疗是否有效? | RCT | 队列研究 |
| 危险因素是什么? | 队列研究 | 病例对照 |
| 疾病多常见? | 横断面研究 | - |
| 罕见病病因? | 病例对照 | 病例系列 |
| 自然病程? | 队列研究 | - |
| 诊断试验准确性? | 横断面研究 | - |

### 2. 根据疾病特征选择

| 疾病特征 | 推荐设计 |
|---------|---------|
| 常见病 | RCT、队列研究 |
| 罕见病 | 病例对照、病例系列 |
| 长潜伏期 | 队列研究 |
| 短病程 | 横断面研究 |
| 需要长期随访 | 队列研究 |

### 3. 根据资源选择

| 资源条件 | 推荐设计 |
|---------|---------|
| 时间充裕、资金充足 | RCT、前瞻性队列 |
| 时间紧迫、资金有限 | 病例对照、横断面 |
| 已有数据库 | 回顾性队列 |

## 第五部分: 样本量计算

### 1. RCT样本量计算

**两均数比较**:
```
n = 2 × [(Zα/2 + Zβ)² × σ²] / δ²
```
- σ: 标准差
- δ: 期望检测的组间差异
- Zα/2: 1.96 (α=0.05双侧)
- Zβ: 0.84 (Power=80%) 或 1.28 (Power=90%)

**两率比较**:
```
n = [Zα/2√(2p̄(1-p̄)) + Zβ√(p1(1-p1)+p2(1-p2))]² / (p1-p2)²
```

**R代码**:
```r
library(pwr)

# t检验样本量
pwr.t.test(d=0.5, sig.level=0.05, power=0.8, type="two.sample")

# 两比例检验
pwr.2p.test(h=ES.h(p1=0.3, p2=0.5), sig.level=0.05, power=0.8)

# 使用samplesize包
library(samplesize)

# 均数比较
n.ttest(power=0.8, alpha=0.05, mean.diff=5, sd=10)
```

### 2. 队列研究样本量

**基于RR**:
```
n = [Zα/2√(2p̄(1-p̄)) + Zβ√(p1(1-p1)+p2(1-p2))]² / (p1-p2)²
```
其中 p1 = p0 × RR

### 3. 病例对照研究样本量

**基于OR**:
```
n = [(Zα/2√(2p̄(1-p̄)) + Zβ√(p1(1-p1)+p2(1-p2))) / (p1-p2)]²
```
其中 p1 = (OR × p0) / (1 - p0 + OR × p0)

## 第六部分: 偏倚与控制

### 1. 选择偏倚 (Selection Bias)

**类型**:
- 入院率偏倚
- 志愿者偏倚
- 失访偏倚

**控制方法**:
- 随机抽样
- 提高应答率
- 减少失访

### 2. 信息偏倚 (Information Bias)

**类型**:
- 回忆偏倚 (病例对照)
- 调查者偏倚
- 测量偏倚

**控制方法**:
- 盲法
- 标准化测量
- 客观指标

### 3. 混杂偏倚 (Confounding Bias)

**定义**: 与研究因素和结局均相关的第三方因素

**控制方法**:

| 阶段 | 方法 | 说明 |
|------|------|------|
| 设计阶段 | 限制 | 限制混杂因素范围 |
| 设计阶段 | 匹配 | 按混杂因素配对 |
| 设计阶段 | 随机化 | RCT中随机分配 |
| 分析阶段 | 分层分析 | 按混杂因素分层 |
| 分析阶段 | 多变量分析 | 回归模型调整 |
| 分析阶段 | 倾向评分 | 观察性研究 |

## 第七部分: 眼科研究设计特殊考虑

### 1. 双眼问题

**设计选择**:

| 方案 | 方法 | 优点 | 缺点 |
|------|------|------|------|
| 单眼设计 | 随机选择一只眼 | 简单 | 损失信息 |
| 双眼设计 | 每只眼独立分析 | 充分利用 | 需调整相关性 |
| 患者水平 | 双眼平均 | 避免相关 | 忽略眼间差异 |

**统计处理**:
- 使用混合效应模型
- GEE (广义估计方程)
- 聚类稳健标准误

### 2. 视力终点选择

| 终点 | 说明 | 适用 |
|------|------|------|
| **视力变化** | 字母数变化 | 大多数试验 |
| **视力维持** | 避免视力下降 | 进展性疾病 |
| **解剖终点** | OCT参数 | 早期试验 |
| **复合终点** | 视力+解剖 | 综合评估 |

### 3. 影像判读标准化

- 中央读片中心
- 双人独立判读
- 不一致时第三方仲裁
- 定期质量控制

## 第八部分: 报告规范

### 1. CONSORT声明 (RCT)

**核心要素**:
- 标题和摘要标识
- 引言 (科学背景、 rationale)
- 方法 (参与者、干预、结局、样本量、随机化、盲法、统计方法)
- 结果 (流程图、招募、基线、分析数、结局、辅助分析、不良反应)
- 讨论 (局限性、可推广性、解释)

### 2. STROBE声明 (观察性研究)

- 标题和摘要
- 引言
- 方法 (研究设计、研究对象、变量、数据来源、偏倚、样本量、统计方法)
- 结果 (参与者、描述性数据、结局数据、主要结果、其他分析)
- 讨论

### 3. 其他规范

| 研究类型 | 规范 |
|---------|------|
| 诊断试验 | STARD |
| 系统综述 | PRISMA |
| 病例报告 | CARE |
| 预测模型 | TRIPOD |
