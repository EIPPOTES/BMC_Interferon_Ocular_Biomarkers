## 🔍 2. 最新优化建议 (网络检索)

### OpenClaw/WSL2 优化要点
根据2025年最新资料，以下是关键优化建议：

#### WSL2 内存优化
1. **设置内存限制**: 在 `.wslconfig` 中配置 `memory=8GB` 防止WSL2占用过多Windows内存
2. **启用zswap**: 通过压缩页面减少swap写入，显著提升swap操作速度
3. **限制处理器核心数**: 配置 `processors=4` 避免占用全部CPU资源

#### 磁盘空间管理
1. **定期清理**: 使用 `wsl --manage <distro> --resize` 调整VHD大小
2. **清理包缓存**: `sudo apt clean && sudo apt autoremove`
3. **Docker清理**: `docker system prune && docker volume prune`

#### OpenClaw特定优化
1. **低内存模式**: 如果使用Ollama本地模型，建议配置低内存优化预设
2. **文件系统性能**: 将频繁访问的项目放在WSL2 ext4分区而非/mnt/c挂载点

**来源**: Microsoft Learn, Whitewater Foundry Blog (2025-03), CEO3C (2025-01)
