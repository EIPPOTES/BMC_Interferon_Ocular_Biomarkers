## 局限性

1. **检索范围**: 仅使用OpenAlex数据库，未覆盖PubMed、Google Scholar等
2. **语言限制**: 主要检索英文文献
3. **时效性**: 部分最新文献可能尚未收录
4. **全文获取**: 部分文献非开放获取，无法获取全文
