# 视网膜疾病 (Retinal Diseases)

## 1. 糖尿病视网膜病变 (Diabetic Retinopathy, DR)

### 1.1 流行病学
- 糖尿病患者中DR患病率约35%
- 全球工作年龄人群首位致盲原因
- 视力威胁性DR (VTDR) 约10%

### 1.2 国际临床分级标准 (2002年)

#### 非增殖性糖尿病视网膜病变 (NPDR)
| 分级 | 特征 |
|------|------|
| 轻度 | 仅有微动脉瘤 |
| 中度 | 微动脉瘤 + 其他体征（出血、硬渗、棉絮斑），但未达重度标准 |
| 重度 | 以下任一：四个象限视网膜出血、静脉串珠样改变、IRMA(视网膜内微血管异常) |

#### 增殖性糖尿病视网膜病变 (PDR)
- 新生血管形成 (NV)
- 玻璃体/视网膜前出血
- 纤维血管增殖

### 1.3 糖尿病性黄斑水肿 (DME)

#### 定义
- 视网膜增厚累及黄斑中心
- 视力下降的主要原因

#### 分类
- 中心累及型DME (CI-DME): 中心凹500μm内
- 非中心累及型DME (NCI-DME)

#### 治疗
1. **抗VEGF治疗**（一线）
   - 雷珠单抗 (Ranibizumab)
   - 阿柏西普 (Aflibercept)
   - 贝伐单抗 (Bevacizumab)
   - 法瑞西单抗 (Faricimab)

2. **激光治疗**
   - 局灶/格栅光凝

3. **激素治疗**
   - 地塞米松玻璃体腔植入剂
   - 氟轻松玻璃体腔植入剂

4. **手术治疗**
   - 玻璃体切除术（难治性DME）

### 1.4 筛查指南
- 1型糖尿病：青春期后5年或12岁开始，每年1次
- 2型糖尿病：确诊时即开始，每年1次
- 妊娠糖尿病：妊娠早期检查，每3个月1次

## 2. 年龄相关性黄斑变性 (Age-related Macular Degeneration, AMD)

### 2.1 流行病学
- 50岁以上人群主要致盲原因
- 发达国家老年人群失明主因

### 2.2 分类

#### 干性AMD (非新生血管性)
- 玻璃膜疣
- 地图样萎缩 (GA)
- 进展缓慢

#### 湿性AMD (新生血管性/渗出性)
- 脉络膜新生血管 (CNV)
- 快速视力下降

### 2.3 AREDS分类系统

| 分类 | 特征 | 进展风险 |
|------|------|---------|
| 早期AMD | 少量小玻璃膜疣 | 低 |
| 中期AMD | 大量小玻璃膜疣或少量大玻璃膜疣 | 中 |
| 晚期AMD | 任一：地图样萎缩、CNV、PED | 高 |

### 2.4 治疗

#### 新生血管性AMD (nAMD)
1. **抗VEGF治疗**（一线）
   - 雷珠单抗 (Ranibizumab)
   - 阿柏西普 (Aflibercept)
   - 贝伐单抗 (Bevacizumab)
   - 布罗鲁珠单抗 (Brolucizumab)

2. **给药方案**
   - 每月注射
   - 按需治疗 (PRN)
   - 治疗-延长方案 (T&E)

#### 干性AMD
- AREDS2配方维生素（延缓中期向晚期进展）
  - 维生素C、E
  - 锌
  - 铜
  - 叶黄素、玉米黄质
- 无有效治疗方法

## 3. 视网膜静脉阻塞 (Retinal Vein Occlusion, RVO)

### 3.1 分类
- 中央视网膜静脉阻塞 (CRVO)
- 半侧视网膜静脉阻塞 (HRVO)
- 分支视网膜静脉阻塞 (BRVO)

### 3.2 临床特征
| 特征 | CRVO | BRVO |
|------|------|------|
| 视力 | 显著下降 | 中度下降 |
| 出血范围 | 全视网膜 | 象限性 |
| 黄斑水肿 | 常见 | 常见 |

### 3.3 治疗
- 抗VEGF治疗（黄斑水肿）
- 激素治疗
- 激光治疗（视网膜缺血）
- 治疗原发病（高血压、糖尿病、高血脂）

## 4. OCT在视网膜疾病中的应用

### 4.1 检查参数
- 中心凹厚度 (CFT)
- 黄斑容积
- 视网膜内液 (IRF)
- 视网膜下液 (SRF)
- 色素上皮脱离 (PED)

### 4.2 疾病监测
- 治疗前基线评估
- 治疗中随访
- 疗效评价
