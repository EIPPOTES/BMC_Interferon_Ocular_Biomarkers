
## ⚠️ 使用注意事项

1. **指南更新**: 临床指南需确认是否为最新版本
2. **引用数据**: 引用次数为动态数据，会随时间变化
3. **OA状态**: 开放获取链接可能因机构订阅变化
4. **临床决策**: 不替代专业医学判断
