# 2026-03-15 亚组分析

## 任务背景
根据HEARTBEAT检查建议和用户要求，进行亚组分析以评估抑郁状态与OCT指标关联在不同人群中的异质性。

## 分析内容
1. **性别分层**: 男性 vs 女性
2. **年龄分层**: 年轻组（<27岁）vs 年长组（≥27岁）
3. **PHQ-9严重程度分层**: 轻度（<10）、中度（10-19）、重度（≥20）
4. **交互作用检验**: 评估亚组差异的统计学显著性

## 分析方法
- **样本量**: 总499眼（抑郁325眼，对照174眼）
- **统计模型**: 线性回归，控制混杂因素
- **关键指标**: 5个最显著的OCT指标
- **软件**: Python 3.x, statsmodels, pandas

## 主要结果

### 1. 性别分层分析

#### 女性组 (n=337眼)
- **Retina_外环颞侧**: β=-6.946, P=5.89e-04***
- **Retina_外环上方**: β=-5.740, P=6.86e-03**
- **Retina_平均厚度**: β=-4.908, P=7.84e-03**
- **Retina_总体积**: β=-0.140, P=7.78e-03**

#### 男性组 (n=126眼)
- 所有指标均未达到统计显著性（P>0.05）
- **Retina_外环颞侧**: β=-5.274, P=0.074（边缘显著）

### 2. 年龄分层分析

#### 年轻组 (<27岁, n=228眼)
- **Retina_外环颞侧**: β=-5.683, P=4.29e-03**
- **Retina_外环上方**: β=-6.637, P=5.55e-03**
- **Retina_平均厚度**: β=-5.010, P=2.07e-02*
- **Retina_总体积**: β=-0.142, P=2.07e-02*

#### 年长组 (≥27岁, n=235眼)
- 仅Retina_外环颞侧显著：β=-7.015, P=1.49e-02*
- 其他指标均不显著

### 3. PHQ-9严重程度分层（抑郁组内）

| 严重程度 | 样本量 | Retina_外环颞侧（均值±标准差） |
|----------|--------|------------------------------|
| 轻度 (<10) | 157眼 | 267.49 ± 18.57 |
| 中度 (10-19) | 71眼 | 273.62 ± 14.19 |
| 重度 (≥20) | 32眼 | 275.66 ± 19.68 |

**趋势**: PHQ-9评分越高，视网膜厚度有增加趋势（与预期方向相反）

### 4. 交互作用检验结果
所有交互作用均不显著（P>0.05）：
- **性别×抑郁交互**: 所有指标P>0.40
- **年龄×抑郁交互**: 所有指标P>0.05
- **结论**: 抑郁状态与OCT指标的关联在不同亚组中无显著差异

## 关键发现

### 🔍 主要发现
1. **性别差异**: 关联在女性中更显著，男性中较弱
2. **年龄差异**: 年轻组多个指标显著，年长组仅外环颞侧显著
3. **症状严重度**: PHQ-9评分与视网膜厚度无明确线性关系
4. **效应异质性**: 交互作用检验未发现显著亚组差异

- **女性显著**: 多个指标在女性中显著，男性中不显著
- **年轻组显著**: 年轻患者多个指标显著，年长患者较少

## 临床与科研意义

### 1. **性别特异性**
- 抑郁对女性视网膜的影响可能更明显
- 可能与激素、社会心理因素差异有关
- 需要进一步研究性别特异性机制

### 2. **年龄效应**
- 年轻抑郁患者视网膜改变更广泛
- 年长患者可能受年龄相关退行性变影响
- 年龄可能是调节因素而非效应修饰因素

### 3. **症状严重度**
- PHQ-9评分与视网膜厚度无线性关系
- 可能提示"全或无"效应而非剂量反应关系
- 或反映抑郁异质性（不同亚型）

### 4. **方法学考虑**
- 男性样本量较小（n=126），统计功效有限
- PHQ-9数据缺失较多（47.9%），影响分层分析
- 需要更大样本验证亚组发现
