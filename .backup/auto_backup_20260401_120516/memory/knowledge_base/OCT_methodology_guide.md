## 📏 黄斑区测量标准

### 黄斑分区定义 (ETDRS Grid)

```
        外上(S)    内上(I)    中央(C)    内下(J)    外下(K)
           │          │          │          │          │
        ╔═══════╦══════════╦══════════╦══════════╗
        ║  S1   ║   S2     ║   C1     ║   S3     ║
        ╠═══════╬══════════╬══════════╬══════════╣
        ║  I1   ║   I2     ║   C2     ║   I3     ║
        ╠═══════╬══════════╬══════════╬══════════╣
        ║  J1   ║   J2     ║   C3     ║   J3     ║
        ╠═══════╬══════════╬══════════╬══════════╣
        ║  K1   ║   K2     ║   K3     ║   K4     ║
        ╚═══════╩══════════╩══════════╩══════════╝
```

### 标准测量参数

| 区域 | 直径 | 包含内容 |
|------|------|----------|
| 中央区 (Central) | 1mm | 黄斑中心凹 |
| 内环 (Inner) | 3mm | 内上、内下、内鼻、内颞 |
| 外环 (Outer) | 6mm | 外上、外下、外鼻、外颞 |

### OCT-MDD研究关键指标
1. **黄斑总厚度 (Total Macular Thickness)**
   - 定义: 内界膜到视网膜色素上皮的距离
   - 正常值: 250-280μm (中央区)
   - 测量点: 中央1mm区域

2. **黄斑分区厚度**
   - 内环四个象限: S2, I2, 内鼻, 内颞
   - 外环四个象限: S3, I3, 外鼻, **外颞(关键)**
   - 平均厚度: 9个区域平均值

3. **视网膜神经纤维层 (RNFL)**
   - 测量位置: 视盘周围3.45mm直径环
   - 分区: 颞侧、上方、鼻侧、下方
   - 平均厚度: 全周平均值

4. **神经节细胞复合体 (GCC)**
   - 组成: RNFL + GCL + IPL
   - 测量区域: 黄斑区6mm×6mm
   - 指标: 平均厚度、最小厚度

## 🔧 质量控制标准

### 图像质量要求
| 参数 | 最低要求 | 理想值 |
|------|----------|--------|
| 信号强度 (Signal Strength) | >6 | >8 |
| 图像清晰度 | 可辨识各层 | 各层清晰 |
| 中心定位 | 中心凹在中心 | ±0.5mm内 |

### 排除标准
- 信号强度 < 6
- 严重屈光间质混浊
- 注视不良导致图像偏移
- 视网膜疾病影响测量

### 双眼测量一致性
- 同一设备、同一操作者
- 测量时间相近 (同一次随访)
- 测量模式一致 (macular cube)

## 📊 统计分析要点

### 双眼数据相关性处理
```
方法1: 随机选择一只眼
优点: 简单，符合独立性假设
缺点: 信息损失

方法2: 双眼平均值
优点: 利用全部数据
缺点: 样本量减少

方法3: 混合效应模型 (推荐)
优点: 考虑双眼相关性，保留全部数据
模型: Y = β0 + β1*Group + β2*Eye + (1|Subject) + ε
```

### 协变量控制
必控变量:
- 年龄 (视网膜厚度随年龄减少)
- 性别 (女性通常略薄)
- 眼轴长度 (长眼轴者较薄)
- 球形等效度数 (近视影响测量)

可选变量:
- 病程
- 症状严重程度 (HAMD评分)
- 治疗状态
- 合并疾病

## 🎯 研究设计建议

### 样本量计算
```
参数:
- 效应量 (Cohen's d): 0.4 (中等)
- 检验效能: 80%
- 显著性水平: 0.05 (双侧)
- 组间比例: 1:1

计算结果:
- 每组需要: 约100例
- 考虑20%失访: 每组125例
- 双眼数据: 可考虑减少20-30%
```

### 测量协议
1. **基线测量**
   - 双眼同时测量
   - 重复3次取平均值
   - 记录测量时间和操作者

2. **随访测量**
   - 同一设备
   - 同一时间段 (减少昼夜变异)
   - 记录可能影响测量的因素

3. **数据管理**
   - 即时备份
   - 双人核查
   - 异常值标记

## ⚠️ 常见问题与解决方案

### 问题1: 测量值波动
**原因**: 测量时间、瞳孔大小、注视差异
**解决**: 标准化测量流程，固定测量时间

### 问题2: 图像质量不佳
**原因**: 屈光间质混浊、干眼、注视不良
**解决**: 人工泪液、充分暗适应、训练注视

### 问题3: 分层错误
**原因**: 自动分层算法误差
**解决**: 手动校正，记录校正比例

### 问题4: 数据缺失
**原因**: 图像质量差、患者不配合
**解决**: 预设替代测量方案，记录缺失原因
