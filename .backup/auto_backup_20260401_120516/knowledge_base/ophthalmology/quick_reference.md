# 眼科专业知识快速参考卡

## 📊 关键数据速查

### 正常眼参数
| 参数 | 正常值 | 备注 |
|------|--------|------|
| 眼压 | 10-21 mmHg | Goldmann压平眼压计 |
| 中央角膜厚度 | 520-570 μm | 影响眼压测量 |
| 前房深度 | 2.5-3.0 mm | 闭角型青光眼筛查 |
| 眼轴长度 | 23-24 mm | 屈光不正相关 |
| 平均RNFL厚度 | 90-110 μm | OCT测量 |
| 中心凹厚度 | 250-280 μm | OCT测量 |

### 青光眼诊断
| 指标 | 异常阈值 |
|------|---------|
| 眼压 | >21 mmHg |
| 垂直C/D比 | >0.5 或双眼差>0.2 |
| 下方RNFL | <100 μm |
| 上方RNFL | <95 μm |
| PSD | >6 dB |

### 糖尿病视网膜病变筛查
| 类型 | 筛查时间 | 频率 |
|------|---------|------|
| 1型糖尿病 | 青春期后5年或12岁 | 每年1次 |
| 2型糖尿病 | 确诊时 | 每年1次 |
| 妊娠糖尿病 | 妊娠早期 | 每3个月1次 |

## 🔬 影像检查

### OCT测量要点
- 信号强度 >6/10
- 扫描中心对准黄斑/视盘
- 避免运动伪影
- 定期校准设备

### OCTA分层
1. 浅层毛细血管丛
2. 深层毛细血管丛
3. 外层视网膜
4. 脉络膜毛细血管层

---

## ⚠️ 紧急情况

### 需紧急处理
- 急性闭角型青光眼发作
- 视网膜中央动脉阻塞 (<90分钟)
- 视网膜脱离（累及黄斑）
- 眼内炎
- 化学伤

### 24小时内处理
- 视网膜分支动脉阻塞
- 玻璃体积血
- 急性视神经炎
