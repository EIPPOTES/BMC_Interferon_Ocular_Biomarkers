## 一、OCT视网膜分层解剖

### 标准分层（从内至外）

| 层数 | 结构名称 | OCT特征 | 临床意义 |
|------|---------|---------|----------|
| 1 | 内界膜 (ILM) | 高反射线 | ERM手术标志 |
| 2 | 神经纤维层 (RNFL) | 高反射层 | 青光眼早期诊断 |
| 3 | 神经节细胞层 (GCL) | 中等反射 | 神经退行性疾病研究 |
| 4 | 内丛状层 (IPL) | 中等反射 | 与GCL合称GCC |
| 5 | 内核层 (INL) | 低反射 | 黄斑水肿定位 |
| 6 | 外丛状层 (OPL) | 中等反射 | 囊样水肿常见部位 |
| 7 | 外核层 (ONL) | 低反射 | 光感受器胞体 |
| 8 | 外界膜 (ELM) | 高反射细线 | 光感受器完整性标志 |
| 9 | 椭圆体区 (EZ/IS/OS) | 高反射带 | **最重要的预后指标** |
| 10 | 嵌合区 (IZ) | 高反射带 | 视锥细胞外节 |
| 11 | RPE/Bruch膜 | 高反射带 | AMD诊断关键 |
| 12 | 脉络膜毛细血管 | 低反射层 | 增强深度成像可见 |

## 二、黄斑区OCT测量参数

### 2.1 黄斑厚度分区（ETDRS网格）

```
        ┌─────────┬─────────┬─────────┐
        │  S3     │   S2    │   S1    │  ← 外环上
        │(3.0mm)  │(3.0mm)  │(3.0mm)  │
        ├─────────┼─────────┼─────────┤
   I3   │  N3     │   N2    │   N1    │  I1
 (3.0mm)│(3.0mm)  │(3.0mm)  │(3.0mm)  │(3.0mm)
   外环鼻│  内环鼻  │  中心凹  │  内环颞  │ 外环颞
        │         │(1.0mm)  │         │
        ├─────────┼─────────┼─────────┤
        │  T3     │   T2    │   T1    │  ← 外环下
        │(3.0mm)  │(3.0mm)  │(3.0mm)  │
        └─────────┴─────────┴─────────┘
        
   中心凹 (C): 直径1mm
   内环 (N1-3, T1-3, S1-3, I1-3): 直径3mm
   外环: 直径6mm
```

### 2.2 关键测量指标

#### 黄斑中心凹厚度 (Central Foveal Thickness, CFT)
- **正常值**: 250-280 μm（SD-OCT）
- **性别差异**: 男性略厚于女性
- **年龄因素**: 随年龄轻度增加
- **临床意义**: 黄斑水肿、萎缩的主要指标

#### 黄斑体积 (Macular Volume)
- **计算方法**: 各分区厚度×面积之和
- **正常值**: 约6.5-8.0 mm³
- **应用场景**: 随访疾病进展

#### 内层视网膜厚度 (Inner Retinal Thickness)
- **组成**: RNFL + GCL + IPL
- **缩写**: GCC (Ganglion Cell Complex)
- **正常值**: 
  - 平均GCC厚度: 90-110 μm
  - 黄斑中心区: 最薄
  - 旁中心凹: 最厚

#### 外层视网膜厚度 (Outer Retinal Thickness)
- **组成**: ONL + 光感受器层 + RPE
- **临床意义**: 光感受器完整性评估

## 三、视盘OCT测量参数

### 3.1 视网膜神经纤维层 (RNFL) 厚度

#### 分区测量
| 分区 | 正常值范围 | 诊断意义 |
|------|-----------|----------|
| 全周平均 | 90-110 μm | 青光眼筛查 |
| 上方 | 120-140 μm | 青光眼最早受累 |
| 下方 | 120-140 μm | 青光眼早期改变 |
| 鼻侧 | 70-90 μm | 相对保留区 |
| 颞侧 | 60-80 μm | 黄斑束走行区 |

#### 青光眼诊断截断值
- **黄色警告**: 厚度 < 第5百分位
- **红色警报**: 厚度 < 第1百分位
- **双眼差异**: > 9 μm 为异常

### 3.2 视盘结构参数

| 参数 | 定义 | 正常范围 | 青光眼改变 |
|------|------|---------|-----------|
| 视盘面积 | 视盘边界内面积 | 1.5-2.5 mm² | 大视盘假阴性 |
| 杯盘比 (C/D) | 杯径/盘径 | < 0.5 | 增大 |
| 盘沿面积 | 神经视网膜边缘 | > 1.0 mm² | 减小 |
| 杯容积 | 视杯容积 | < 0.3 mm³ | 增大 |

## 四、疾病特异性OCT表现

### 4.1 糖尿病视网膜病变

#### 糖尿病性黄斑水肿 (DME) 分型
| 类型 | OCT特征 | 治疗策略 |
|------|---------|----------|
| 弥漫性视网膜增厚 (DRT) | 广泛视网膜增厚，囊样改变不明显 | 抗VEGF |
| 囊样黄斑水肿 (CME) | 视网膜内低反射囊腔 | 抗VEGF/激素 |
| 浆液性视网膜脱离 (SRD) | 视网膜下液体积聚 | 抗VEGF |
| 牵引性黄斑水肿 | 玻璃体视网膜牵拉 | 玻璃体手术 |

#### 中心受累型DME (CI-DME)
- **定义**: 中心1mm区域视网膜增厚
- **治疗指征**: 视力<20/25且存在CI-DME
- **随访**: 每月OCT监测

### 4.2 年龄相关性黄斑变性 (AMD)

#### 干性AMD特征
| 分期 | OCT表现 |
|------|---------|
| 早期 | 玻璃膜疣（小/中等） |
| 中期 | 大玻璃膜疣、RPE不规则 |
| 晚期 | 地图样萎缩（GA）- RPE和外层视网膜丢失 |

#### 湿性AMD特征
- **视网膜下高反射物质**: 提示CNV活动
- **视网膜下液体**: 新鲜渗出标志
- **视网膜内液体**: 预后较差
- **PED**: 纤维血管性PED vs 浆液性PED
- **双轨征**: RPE脱离伴CNV

#### nAMD治疗反应评估
| 治疗反应 | OCT标准 |
|---------|---------|
| 完全应答 | 无视网膜内/下液体 |
| 部分应答 | 液体减少但未完全吸收 |
| 无应答 | 液体持续存在或增加 |
| 复发 | 液体再次出现 |

### 4.3 视网膜静脉阻塞

#### 黄斑水肿OCT特征
- 弥漫性视网膜增厚
- 囊样改变（外丛状层为主）
- 视网膜下液体（部分病例）
- 高反射点（硬性渗出）

#### 治疗监测
- **基线**: 中央黄斑厚度(CMT)
- **治疗目标**: CMT < 300 μm
- **随访频率**: 每月至每2月

### 4.4 中心性浆液性脉络膜视网膜病变 (CSC)

#### 急性CSC OCT特征
- 神经感觉视网膜脱离
- RPE脱离（可合并存在）
- 视网膜下高反射沉积物（纤维蛋白）
- 脱离下方RPE不规则

#### 慢性CSC OCT特征
- 持续性视网膜下液体
- 弥漫性RPE功能障碍
- 外层视网膜萎缩（EZ缺失）
- 继发性CNV（并发症）

#### 增强深度成像 (EDI-OCT)
- 脉络膜厚度显著增加（>400 μm）
- 大血管层血管扩张
- 诊断和随访的重要工具

## 五、OCT质量控制

### 5.1 图像质量指标

| 参数 | 标准 | 意义 |
|------|------|------|
| 信号强度 (SI) | > 6/10 | 图像可信度 |
| 信噪比 (SNR) | > 25 dB | 分层识别能力 |
| 扫描质量 | 无显著伪影 | 测量准确性 |

### 5.2 常见伪影识别

| 伪影类型 | 表现 | 处理 |
|---------|------|------|
| 镜面伪影 | 图像倒置重复 | 调整Z轴位置 |
| 渐晕伪影 | 一侧信号衰减 | 充分散瞳 |
| 眨眼线 | 水平黑线 | 重新扫描 |
| 玻璃体混浊阴影 | 下方信号减弱 | 选择清晰切面 |
| 分割错误 | 分层线错位 | 手动校正 |

### 5.3 测量重复性

- **同一操作者**: CV < 2%
- **不同操作者**: CV < 3%
- **随访变化**: > 5% 考虑临床意义

## 六、OCT新技术

### 6.1 OCT血管成像 (OCTA)

#### 血管分层
| 层次 | 深度范围 | 临床应用 |
|------|---------|----------|
| 浅层毛细血管丛 | 神经纤维层-GCL | 青光眼、DR |
| 深层毛细血管丛 | IPL-INL | DR、RVO |
| 外层视网膜 | OPL-RPE | CNV检测 |
| 脉络膜毛细血管 | RPE下方 | CSC、AMD |

#### 定量指标
- 血管密度 (Vessel Density, VD)
- 灌注密度 (Perfusion Density, PD)
- 无灌注区面积 (FAZ area)

### 6.2 扫频源OCT (SS-OCT)

#### 优势
- 更深组织穿透（至巩膜）
- 更快扫描速度
- 更大成像范围
- 更少运动伪影

#### 临床应用
- 高度近视后极部成像
- 脉络膜厚度测量
- 玻璃体视网膜界面评估

## 七、OCT在神经精神疾病中的应用

### 7.1 视网膜神经纤维层 (RNFL) 研究

#### 多发性硬化 (MS)
- 视神经炎后RNFL变薄
- 平均RNFL与脑萎缩相关
- 预测疾病进展的生物标志物

#### 阿尔茨海默病 (AD)
- 上方和下方RNFL变薄
- GCC厚度与认知评分相关
- 早期诊断潜在工具

#### 帕金森病 (PD)
- 黄斑区GCC变薄
- 与疾病严重程度相关
- 多巴胺能神经元变性的窗口

### 7.2 视网膜与脑的联系

| 解剖特点 | 临床意义 |
|---------|----------|
| 视网膜是中枢神经系统的延伸 | 视网膜病变反映脑内变化 |
| 血-视网膜屏障类似血-脑屏障 | 血管性疾病共同受累 |
| 视网膜缺乏髓鞘 | 更早显示轴索损伤 |
| 可直接无创观察 | 理想的神经退行性疾病监测窗口 |
