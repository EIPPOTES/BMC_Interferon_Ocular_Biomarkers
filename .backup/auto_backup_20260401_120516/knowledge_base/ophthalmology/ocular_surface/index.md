# 眼表疾病 (Ocular Surface Diseases)

## 概述
眼表疾病包括干眼病、睑板腺功能障碍、角结膜炎等。本目录收录眼表疾病的权威临床指南与共识。

## 诊断标准
- 干眼病的诊断基于症状、泪膜稳定性、眼表染色等多项指标。
- TFOS DEWS III 提供了标准化的诊断流程。

## 治疗原则
- 一线治疗：人工泪液、热敷、睑板腺按摩。
- 二线治疗：抗炎药物（环孢素、利非斯特）、泪点栓塞。
- 三线治疗：自体血清、手术治疗。
